# Windows Sysmon Security Incident Analysis

## Project Overview

This project demonstrates the use of Microsoft Sysmon and Windows Event Viewer for security monitoring, threat hunting, and incident investigation.

Sysmon provides enhanced visibility into system activity by generating detailed event logs related to process execution, network connections, file creation, DNS queries, registry modifications, and image loading activities.

The objective of this project was to investigate Windows system activity, identify potentially suspicious behavior, and map observed events to the MITRE ATT&CK framework.

---

## Objectives

- Deploy and validate Sysmon logging
- Analyze Windows security telemetry
- Investigate process creation activity
- Monitor network connections
- Track file creation events
- Analyze DLL/Image loading events
- Review DNS query activity
- Identify security-relevant artifacts
- Map findings to MITRE ATT&CK
- Produce SOC-style investigation documentation
