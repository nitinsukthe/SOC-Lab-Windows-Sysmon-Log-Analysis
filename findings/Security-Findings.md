# Security Findings

## Executive Summary

A detailed analysis of Windows Sysmon telemetry was performed to identify suspicious activities, investigate endpoint behavior, and validate security monitoring capabilities.

The investigation focused on process creation, network communications, file creation events, image loads, DNS queries, and registry modifications.

No Indicators of Compromise (IOCs) were identified during the investigation.

---

# Finding 1: Process Creation Activity

## Event ID

1 – Process Creation

## Observed Activity

Processes observed:

- cmd.exe
- ipconfig.exe
- rundll32.exe

## Analysis

The identified processes were executed by the authenticated user account and demonstrated normal administrative and system discovery behavior.

No evidence of:

- PowerShell abuse
- Encoded commands
- Malicious script execution
- Living-off-the-Land abuse

was identified.

## Severity

Informational

## MITRE ATT&CK

- T1059 – Command and Scripting Interpreter
- T1016 – System Network Configuration Discovery
- T1033 – System Owner/User Discovery

---

# Finding 2: Network Connection Activity
